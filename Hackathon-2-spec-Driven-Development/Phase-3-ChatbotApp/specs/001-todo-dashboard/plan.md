## Summary

Build a 2026-modern, error-free, responsive Todo dashboard frontend using Next.js 15+ with App Router. The implementation delivers:
- Authentication flow (signup, login, logout) with Better Auth
- Task CRUD operations with optimistic updates
- Responsive design (cards on mobile, table on desktop)
- Dark/light mode with system preference detection
- Comprehensive error handling with zero crashes

## 1. High-Level Architecture Overview

### Next.js App Router Strategy

```
app/
├── layout.tsx          → Root: Providers, global styles, metadata
├── (auth)/             → Route group: Public auth pages
│   └── layout.tsx      → Centered layout with glass effect
└── (protected)/        → Route group: Auth-required pages
    └── layout.tsx      → Header, auth guard, nav
```

**Key Decisions**:
- Route groups `(auth)` and `(protected)` for layout separation
- Server Components for layouts and initial renders
- Client Components for interactive elements (forms, modals, toggles)

### Server vs Client Components

| Layer | Component Type | Rationale |
|-------|---------------|-----------|
| Layouts | Server | Static structure, metadata |
| Pages (initial) | Server | SEO, fast initial load |
| Forms | Client | User interaction, validation |
| Task List | Client | Optimistic updates, real-time |
| Modals | Client | User interaction |
| Theme Toggle | Client | State changes |

```
Error Boundary Hierarchy:
1. global-error.tsx   → Catches root errors, shows recovery UI

```

- **Optimistic Updates**: React Query's `onMutate` → `onError` rollback pattern

### API Client (`lib/api.ts`)

**Features**:
- JWT token management
- Automatic 401 → login redirect
- Type-safe request/response
- Error transformation to user-friendly messages

```typescript
class ApiClient {
  private async request<T>(endpoint: string, options?: RequestInit): Promise<T> {
    try {
      const response = await fetch(`${API_BASE}${endpoint}`, {
        ...options,
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${getToken()}`,
          ...options?.headers,
        },
      });

      if (response.status === 401) {
        clearAuth();
        window.location.href = '/login?session=expired';
        throw new Error('Session expired');
      }

      const data = await response.json();

      if (!response.ok) {
        throw new ApiError(data.error.message);
      }

      return data;
    } catch (error) {
      if (error instanceof ApiError) throw error;
      throw new ApiError('Unable to connect. Please check your connection.');
    }
  }
}
```

### Optimistic Updates Pattern

```typescript
// hooks/useTasks.ts
export function useCreateTask() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: api.tasks.create,
    onMutate: async (newTask) => {
      await queryClient.cancelQueries({ queryKey: ['tasks'] });
      const previous = queryClient.getQueryData(['tasks']);

      // Optimistic add
      queryClient.setQueryData(['tasks'], (old: TaskListResponse) => ({
        ...old,
        tasks: [...old.tasks, { ...newTask, id: `temp-${Date.now()}`, completed: false }],
      }));

      return { previous };
    },
    onError: (err, newTask, context) => {
      // Rollback
      queryClient.setQueryData(['tasks'], context?.previous);
      toast.error('Failed to create task. Please try again.');
    },
    onSuccess: () => {
      toast.success('Task created successfully!');
    },
    onSettled: () => {
      queryClient.invalidateQueries({ queryKey: ['tasks'] });
    },
  });
}
```

## 6. Authentication Flow

### Better Auth Integration

```typescript
// lib/auth.ts
import { createClient } from 'better-auth';

export const authClient = createClient({
  baseUrl: process.env.NEXT_PUBLIC_API_URL,
});

// Token storage
export function setToken(token: string) {
  localStorage.setItem('auth_token', token);
}

export function getToken(): string | null {
  if (typeof window === 'undefined') return null;
  return localStorage.getItem('auth_token');
}

export function clearAuth() {
  localStorage.removeItem('auth_token');
}
```

### Protected Routes Pattern

```tsx
// app/(protected)/layout.tsx
'use client';

import { useEffect } from 'react';
import { useRouter } from 'next/navigation';
import { useAuth } from '@/hooks/useAuth';

export default function ProtectedLayout({ children }) {
  const { isAuthenticated, isLoading } = useAuth();
  const router = useRouter();

  useEffect(() => {
    if (!isLoading && !isAuthenticated) {
      router.push('/login');
    }
  }, [isAuthenticated, isLoading, router]);

  if (isLoading) {
    return <FullPageSpinner />;
  }

  if (!isAuthenticated) {
    return null; // Will redirect
  }

  return (
    <div className="min-h-screen">
      <Header />
      <main className="container mx-auto px-4 py-8">
        {children}
      </main>
    </div>
  );
}
```
