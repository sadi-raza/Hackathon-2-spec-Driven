## Prompt

# Project Constitution: Todo Evolution – Hackathon II
## Project Name: hackathon-todo
## Vision: Build the ultimate AI-native Todo application that evolves from a simple console app to a fully cloud-native, event-driven, AI-powered distributed system – all through 100% spec-driven development.

## Core Principles (Non-Negotiable – Zero Tolerance)

1. **Zero Manual Coding Allowed**
   - Every line of code (Python, TypeScript, YAML, Docker, Helm, etc.) MUST be generated by Claude Code after refining specifications.
   - Manual edits only for fixing syntax errors (must be documented in commit with Task ID).
   - Judges will review Claude Code prompts, iterations, and chat history.

2. **Spec-Driven Development is the Single Source of Truth**
   - All features, architecture, APIs, database schema, UI components, deployment configs MUST originate from /specs/ folder.
   - Every implementation MUST trace back to a Task ID → Plan → Specify → Constitution.
   - Use @specs/path/to/file.md referencing in all prompts.

3. **Reusable Intelligence Mandatory (+200 Bonus Target)**
   - Actively create and use at least 7 Agent Skills in .claude/skills/
   - Actively create and use at least 7 Subagents in .claude/agents/
   - Delegation required: Orchestrator → specialized agents → skills
   - Skills and subagents MUST be reused across phases
   - Demonstrate clear delegation in prompts and commits

4. **Phase Evolution Constraints**
   - Phase I: In-memory console with Basic + Intermediate + Advanced features
   - Phase II: Full-stack web with Better Auth JWT, Neon DB, user isolation
   - Phase III: AI-powered chatbot with OpenAI Agents SDK + Official MCP SDK
   - Phase IV: Local Kubernetes with Minikube, Helm, kubectl-ai
   - Phase V: Cloud deployment with Kafka, Dapr, DigitalOcean DOKS, event-driven architecture

5. **Security & Quality Standards**
   - User isolation enforced at every level
   - JWT authentication compulsory from Phase II
   - Input validation and sanitization on all endpoints
   - Consistent response formatting
   - Responsive, professional UI from Phase II
   - Integration testing after every major feature

6. **Monorepo & Structure Compliance**
   - Monorepo structure exactly as specified
   - Spec-Kit Plus configuration mandatory
   - Multiple layered CLAUDE.md files
   - Organized /specs folder with features/api/database/ui

7. **Bonus Features Targeted (+600 Possible)**
   - Reusable Intelligence via subagents and skills (+200)
   - Cloud-Native Blueprints (+200)
   - Multi-language Support – Urdu in chatbot (+100)
   - Voice Commands (+200)

8. **Deliverables Excellence**
   - Public GitHub repo with clean history
   - Comprehensive README with setup and demo
   - 90-second demo videos showing spec → implementation flow
   - Clear commit messages with Task IDs
   - Live presentation ready (if invited)

9. **Violation Hierarchy**
   - Constitution > Specify > Plan > Tasks
   - Any conflict: Constitution wins
   - Any agent violating these rules MUST stop and request clarification

## Final Goal
This constitution governs the complete evolution of the Todo application. Every line of code, every design decision, every commit must serve the vision of becoming an AI Startup Founder through excellence in spec-driven, agentic development.

We do not build average apps.
We build systems that win hackathons and launch careers.

All agents, subagents, and skills MUST adhere strictly to these principles.

— The Todo Evolution Team | Targeting Top 1 | January 2026
