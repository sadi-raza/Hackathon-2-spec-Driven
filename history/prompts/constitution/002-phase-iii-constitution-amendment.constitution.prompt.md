## Prompt

# Project Constitution: Todo Evolution – Hackathon II

## Project Name

hackathon-todo

## Vision

Build a multi-phase Todo application that evolves from console → full-stack web → AI-powered chatbot. All development follows strict spec-driven principles using Claude Code and Spec-Kit Plus. No manual coding allowed.

## Core Principles (Non-Negotiable)

1. **Spec-Driven Development Only**

   Every feature, endpoint, model, UI component and integration must originate from /specs/ folder.

   Workflow: specify → plan → tasks → Claude Code generation.

2. **Zero Manual Coding**

   All code must be generated by Claude Code.

   Manual edits only for syntax fixes (documented with Task ID).

3. **Phase II Backend as Foundation**

   The FastAPI backend (Neon DB, SQLModel, Better Auth JWT) is the core foundation.

   Phase III chatbot must extend this backend without breaking existing functionality.

4. **Phase III – AI Todo Chatbot Integration**

   - Extend existing FastAPI backend

   - Add stateless /api/{user_id}/chat endpoint

   - Build MCP server (Official MCP SDK) inside backend

   - Expose 5 stateless tools: add_task, list_tasks, complete_task, delete_task, update_task

   - Persist conversation state in Neon DB (Conversation + Message models)

   - Use OpenAI Agents SDK for agent logic

   - Replace OpenAI API with Cohere API key for all LLM calls (both agent + any other reasoning)


5. **Security & Authentication**

Reuse Phase II JWT (Better Auth) for all endpoints including chat.

Strict user isolation – only own tasks visible.

6. **Stateless Design**

Chat endpoint & MCP tools must be stateless.

All state in Neon DB.

7. **Reusable Intelligence**

Must Use and extend existing 10+ agents/skills.

Create new ones for MCP tools, Cohere integration, conversation persistence.

8. **Quality & Traceability**

- Reference specs in every implementation

- Clean commits with Task IDs

- Maintain separation: frontend, backend, MCP, agent logic

9. **Bonus Goals**

 - Urdu support in chatbot (+100)

 - Reusable intelligence demonstration (+200)

## Violation Rules

Any deviation (manual code, breaking Phase II backend, not using Cohere API key for LLM, stateful design) must be corrected immediately.

If in doubt, stop and request clarification.

This constitution governs the project from Phase II onwards, with Phase III chatbot built directly on Phase II backend using Cohere API key for LLM reason
